概述 #
Ultralytics YOLO26 是一套统一的实时视觉模型系列，相关介绍见 Ultralytics YOLO26 论文 。该系列引入了原生端到端推理、更轻量的检测头、更新后的训练方案，以及针对检测、分割、姿态估计、分类和旋转框检测任务设计的专用检测头。
在五种检测模型尺寸中，YOLO26 在 COCO 上达到 40.9-57.5 mAP ，T4 TensorRT 延迟为 1.7-11.8 ms 。论文还报告称，在 Intel Xeon CPU @ 2.00 GHz 上，与 YOLO11n 相比，YOLO26n 的 CPU ONNX 推理速度最高可提升 43% 。
查看 尚未发布的 YOLO27 预览 ，了解计划中的架构、任务和初步基准测试结果。
观看： 如何在 Google Colab 中使用自定义数据集训练 YOLO26 模型。
快速入门
Python CLI
from ultralytics import YOLO
model = YOLO( "yolo26n.pt" ) # 加载一个预训练的 YOLO26n 模型
results = model( "path/to/bus.jpg" ) # 运行推理
在 Ultralytics Platform 上试用
直接在 Ultralytics Platform 上探索和运行 YOLO26 模型。
YOLO26 模型系列围绕四个设计方向构建：
原生端到端推理： 可选的一对一检测头无需非极大值抑制 (NMS) 即可生成预测结果，从而简化部署并减少后处理。
更轻量的边界框回归： YOLO26 移除了分布焦点损失 (DFL)，降低了检测头的复杂度，同时保留不受限制的回归范围。
训练方案更新： 训练流水线结合了 MuSGD （Muon + SGD 混合优化器）、 Progressive Loss 和 STAL （小目标感知标签分配），以改进优化过程、将监督重点转向推理时使用的检测头，并确保小目标有足够的正标签覆盖。已发布检查点所用的完整超参数记录在 YOLO26 训练方案指南 中。
任务专用检测头和损失： YOLO26 针对实例分割、语义分割变体、姿态估计和旋转框检测引入了专门设计，同时让不同任务共用一条模型流水线。
这些更新共同改善了不同模型尺寸和部署目标下准确率与延迟之间的权衡。
主要功能 #
无 DFL 回归 YOLO26 移除了分布焦点损失 (DFL)，降低了检测头的复杂度并简化了导出流程。
端到端无 NMS 推理 YOLO26 支持使用 nms=False 进行 原生端到端 推理，无需单独执行 NMS。默认的一对多路径使用 NMS 来提高准确率。
Progressive Loss + STAL Progressive Loss 将训练重点转向推理时使用的检测头，而 STAL 则提升小目标的正标签覆盖率。
MuSGD 优化器 这是一种结合 SGD 与 Muon 的混合优化器，将大语言模型训练中的优化思路应用于计算机视觉。
高效部署 简化的检测头和可选的无 NMS 路径降低了不同导出目标和硬件配置下的推理开销，其中包括论文报告的 YOLO26n 相比 YOLO11n 的 CPU ONNX 加速效果。
实例分割增强 引入语义分割损失以改善模型收敛，并升级原型模块以利用多尺度信息，从而提升掩码质量。论文报告称，在 COCO 实例分割任务上，相比 YOLO11，边界框 AP 最高提升 +2.5，掩码 AP 最高提升 +3.7。
精准姿态估计 集成 残差对数似然估计 (RLE)，以实现更准确的关键点定位，并优化解码流程来提高推理速度。论文报告称，在 COCO 姿态估计任务上，相比 YOLO11，AP 最高提升 +7.2。
改进的 OBB 解码 引入专用角度损失，以提高正方形目标的检测准确率，并优化 OBB 解码来解决边界不连续问题。论文报告称，在 DOTA-v1.0 旋转框检测任务上，相比 YOLO11，mAP 最高提升 +3.4。

使用示例 #
本节提供简单的 YOLO26 训练和推理示例。有关这些模式及其他 模式 的完整文档，请参阅 预测 、 训练 、 验证 和 导出 文档页面。
请注意，以下示例适用于 YOLO26 检测 模型，用于 目标检测 。有关支持的其他任务，请参阅 分割 、 语义分割 、 深度估计 、 分类 、 姿态估计 和 OBB 文档。
示例
Python CLI
PyTorch 预训练的 *.pt 模型以及配置 *.yaml 文件都可以传递给 YOLO() 类，从而在 Python 中创建模型实例：
from ultralytics import YOLO
# 加载经过 COCO 预训练的 YOLO26n 模型
model = YOLO( "yolo26n.pt" )
# 使用 YOLO26n 模型对“bus.jpg”图像进行推理
results = model( "path/to/bus.jpg" )
# 使用 COCO8 示例数据集训练模型 100 个 epoch
results = model.train(data= "coco8.yaml" , epochs= 100 , imgsz= 640 )
双头架构
YOLO26 检测模型采用 双头架构 ，可灵活适应不同的部署场景：
一对多头（默认） ：生成传统的 YOLO 输出，需要进行 NMS 后处理，输出 (N, nc + 4, 8400) ，其中 nc 是类别数。该检测头通常能达到略高的准确率，但需要额外的处理。
一对一头（ nms=False ） ：生成无需 NMS 的端到端预测，输出 (N, 300, 6) ，每张图像最多检测 300 个目标。该检测头针对快速推理和简化部署进行了优化。
你可以在导出、预测或验证时切换检测头：
Python CLI
from ultralytics import YOLO
model = YOLO( "yolo26n.pt" )
# 使用一对多头（默认，Ultralytics 会应用 NMS）
results = model.predict( "image.jpg" ) # inference
metrics = model.val(data= "coco.yaml" ) # validation
model.export( format = "onnx" ) # export
# 启用无 NMS 的一对一头
results = model.predict( "image.jpg" , nms= False ) # inference
metrics = model.val(data= "coco.yaml" , nms= False ) # validation
model.export( format = "onnx" , nms= False ) # export
预测和验证默认使用一对多头，以确保准确率。使用 nms=False 进行无 NMS 推理，或使用 nms=True 在受支持的导出格式中嵌入 NMS。无论选择哪种方式，两个检测头都会接受训练。有关输出格式和导出兼容性，请参阅 端到端检测指南 。
YOLOE-26：开放词汇检测与分割 #
YOLO26 也支持 YOLOE-26 ，这是一种开放词汇变体，可以根据 文本提示 、 视觉提示 或 无提示模式 检测和分割目标类别，而不是依赖训练时学到的固定类别列表。YOLOE-26 保留了 YOLO26 可选的无 NMS 端到端（e2e）检测头，因此开放词汇推理速度足够快，适用于目标类别会随时间变化的动态环境。YOLOE-26x 在 LVIS minival 上采用文本提示时达到 40.6 AP ，采用视觉提示时达到 38.5 AP ，无提示时达到 31.1 AP ——这些是论文中的非端到端数据，其端到端检测头的结果分别低 1.1、2.3 和 1.2 AP。
有关各尺度的性能表、无提示变体和完整用法示例，请参阅 YOLOE 文档 。

常见问题 #
YOLO26 的主要改进有哪些？
无 DFL 回归 ：简化检测头和导出流程
端到端无 NMS 推理 ：支持使用 nms=False 进行无 NMS 推理
渐进式损失 + STAL ：改善训练对齐效果和小目标标签覆盖率
MuSGD 优化器 ：结合 SGD 与受 Muon 启发的优化方法，实现稳定训练
特定任务的检测头和损失函数 ：改进对分割、姿态估计和有向目标检测的支持
YOLO26 支持哪些任务？
YOLO26 是一个 统一的模型系列 ，可端到端支持多种计算机视觉任务：
目标检测
实例分割
语义分割
单目深度估计
图像分类
姿态估计
有向目标检测（OBB）
每种尺寸变体（n、s、m、l、x）都支持所有任务，还可以通过 YOLOE-26 使用开放词汇版本。
YOLO26 为何适合高效部署？
YOLO26 通过以下方式提升部署效率：
可选的原生端到端推理，无需 NMS（ nms=False ）
无 DFL 回归和更轻量的检测头
导出融合后的模型，移除仅用于训练的辅助组件
与 Intel Xeon CPU @ 2.00 GHz 上的 YOLO11n 相比，YOLO26n 的 CPU ONNX 推理速度最高提升 43%
支持灵活的导出格式，包括 TensorRT、ONNX、CoreML、LiteRT 和 OpenVINO
如何开始使用 YOLO26？
YOLO26 模型可通过 ultralytics 包下载。安装或更新该包，然后加载模型：
from ultralytics import YOLO
# 加载预训练的 YOLO26 nano 模型
model = YOLO( "yolo26n.pt" )
# 对图像进行推理
results = model( "image.jpg" )
有关训练、验证和导出的说明，请参阅 使用示例 部分。
